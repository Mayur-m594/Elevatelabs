The AES Secure File Storage System is a Python-based command-line application designed to protect sensitive data by encrypting files using modern cryptographic standards. It employs AES-256 in GCM mode for strong confidentiality and authenticated encryption, while PBKDF2 is used to derive a secure 256-bit key from a user-provided password, ensuring resistance against brute-force attacks. The system generates an encrypted file along with a metadata file containing essential cryptographic parameters, enabling safe and accurate decryption. During decryption or verification, a SHA-256 hash is computed and compared with stored metadata to confirm file integrity and detect any tampering. With its simple CLI interface, strong encryption mechanisms, and cross-platform compatibility, this project demonstrates the practical importance of data confidentiality, integrity, and secure key management in real-world cybersecurity applications.
